# RSpeech

Safariで開いているページの本文を、VOICEVOXの同じ声で読み上げる小さなMacアプリです。
日本語の途中に英単語があっても、Appleの英語音声へ切り替わりません。

## ダウンロード

**[最新版のダウンロード](https://github.com/haruxbt/RSpeech/releases/latest)** から `RSpeech-v1.4.1-macOS-arm64.zip` を取得してください。ソースコードのZIPではなく、Releases内のアプリ用ZIPを使います。

1. ZIPを展開します。
2. `RSpeech.app` を「アプリケーション」へコピーします。
3. Safariで読みたいページを開き、RSpeechの **▶** を押します。

Apple Silicon向けです。RTranslateでVOICEVOXデータを準備しておく必要があります。PythonやXcodeの別途インストールは不要です。アプリは仮署名・未公証です。初回起動でmacOSの確認が必要になる場合があります。

## 使い方

- **▶**：Safariで本文を数文字ドラッグしてから押すと、選択の先頭から記事末尾まで読みます。選択部分だけではなく、その先も読み進めます。選択がなければ本文全体を読みます。
- **⏸**：一時停止します。もう一度 **▶** を押すと続きから再開します。
- 再生・再開時にSafariのURLが変わっていた場合、以前の本文と再生位置を破棄し、新しいページの本文を先頭から読みます。
- 同じURLでも新しい範囲を選択して **▶** を押すと、その位置から取り直します。同じ選択の一時停止・再開では続きから読みます。
- 一時停止中に選択を解除しても続きから再開します。読み終わった後や停止後に選択を解除すると、次の **▶** は本文全体を取得します。
- **声・速度**は再生中・一時停止中・停止中のどの状態でも変更できます。変更は次の文から反映されます。
- **「取得した本文」**を広げると、読み上げ対象を確認・コピーできます。

記事本文の領域を優先して、記事タイトル・サイトのヘッダー・ナビゲーション・フッターなどを除外します。本文中の小見出しは読みます。ページ構造によっては不要な文が混ざったり、本文を取得できなかったりする場合があります。
ページの再読み込みも検知します。同じページ内で表示内容だけが更新された場合は、読みたい位置を改めて選択してください。
画像・PDFのOCR、翻訳、ページの自動スクロールには対応していません。

## 読み上げ辞書と英単語の確認

右下の歯車またはメニューの「設定…」を開きます。

- **ワード追加・編集**：文字・かな読み・アクセント位置・優先度を指定して登録します。例：`ARTEX` → `アルテックス`。**「試聴」**で登録前に今選んでいる声・速度・アクセントを確認できます。試聴時は本文の再生を一時停止し、本文の▶で再開できます。試聴だけでは保存しません。編集・削除もできます。
- **ページの英単語**：「現在のページの英単語を確認」を押すと、再生と同じ本文から英単語を拾い、VOICEVOXの標準の読みを表示します。同じページ・選択位置で再生用の本文を取得済みの場合は、その本文を再利用します。新しく取得する場合も再生と同じ処理を使います。
- 最初は取得した全単語を表示します。「未登録の綴り読み候補のみ」を選ぶと、共通・個人辞書に未登録で1文字ずつ読む候補へ絞り込めます。該当がない場合はその旨を表示します。
- 「登録する読み」を必要な行に入力して、**「入力した読みをまとめて登録」**を押します。

ハイフン・アポストロフィを含む単語も解析します。1語の読みを取得できない場合も、その語を「読み取得なし」として残し、他の単語の解析を続けます。
CPUのように綴り読みで正しい単語もあるため、候補は誤読の断定ではありません。固有名詞の正しい読みは確認してください。1回に最大200語を解析し、個人辞書は1000件、文字・読みはそれぞれ64文字まで登録できます。
登録した辞書はこのMacに保存します。表示された本文は変えず、音声合成時だけ読みを適用します。英字の大文字・小文字は区別せず、英単語の一部分だけを置き換えないようにします。RTranslateの辞書・モデルは変更しません。
声・速度・辞書の変更は、まだ読み始めていない次の文に反映します。

### GitHubの共通辞書

[共通辞書JSON](Dictionary/common-ja.json)には、IT・プログラミング・AI・セキュリティ、ネットワークメーカー・製品名など789語の初期読みを用意しています。Intent / Planner / Write、put / get / read / write / post、Cisco / Catalyst / Palo Alto / Fortinet / Juniper / Arista / A10 / F5 / CrowdStrike / Zscaler / Infobloxなどを含みます。

公開JSONは更新を継続しており、2026.11.17.1では850語です。Attack Surface / MITRE Att@ck / Tor / Dark Web / DoS / DDoSも含みます。

起動時にGitHubから公開JSONを確認し、検証してからこのMacへ保存します。通信に失敗したときは手元の共通辞書を使います。**同じ単語は個人辞書の登録を優先**するため、更新で自分の読みが上書きされません。

設定の「共通辞書・JSON」から自動更新のON/OFF、今すぐ更新、共通語の検索と読みの修正、個人辞書のJSON取り込み・書き出しができます。アクセント0は平板の初期値、優先度の初期値は5です。読みの好みは個人辞書で調整してください。標準側の「読みを修正」からアクセントも変更できます。

共通辞書を更新した後、単語（英字大小は同一扱い）・読み（かなを正規化）・アクセント・優先度が一致する個人登録は自動で削除します。異なる修正は個人辞書に残して優先します。保存済みの共通辞書で起動する場合にも整理します。
個人辞書を書き出してメンテナーへ提供すると、公開可能な語を確認したうえで読み・アクセント・優先度を標準側へ取り込めます。アプリによる個人辞書の自動送信はありません。

RSpeech形式のJSON配列と、VOICEVOX EngineのUUID形式JSONの基本項目を取り込めます。RSpeechはVOICEVOX Coreを直接使うため、EngineのHTTPサーバーを起動する必要はありません。詳細・出典・編集方法は[共通辞書の説明](Dictionary/README.md)にあります。

## 文間の待ち時間

現在の文を再生している間に、次の1文を合成します。声・速度・辞書を変更した場合は、次の文を新しい設定で作り直します。
句点などの自然な間は残ります。合成が再生に追いつかない場合や設定を変更した直後には、待ち時間が生じることがあります。

## Safariの初回設定

macOSがSafariの操作許可を求めた場合は、ご本人が内容を確認して許可してください。拒否した場合は、システム設定 → プライバシーとセキュリティ → オートメーションでRSpeechのSafari操作許可を確認します。

SafariでJavaScriptの実行が禁止されている場合は、Safariの設定 → 詳細で開発者向け機能を表示し、開発メニューの **「Apple EventsからのJavaScriptを許可」** を有効にしてください。OSによって表示名は異なります。

## 音声・プライバシー

四国めたん・ずんだもん・春日部つむぎ・雨晴はう・冥鳴ひまり・雀松朱司のノーマル音声を選べます。速度は0.75〜2倍です。英単語の発音はVOICEVOXの辞書に依存します。

本文・URL・生成音声・ページの単語解析結果はメモリで扱い、保存・ログ出力・外部送信しません。GitHubへの通信は固定URLの公開辞書JSONの取得だけで、本文や個人辞書を送信しません。音声合成用のHTTPサーバーも起動しません。声・速度、登録した辞書の文字・読み・アクセント・優先度、公開共通辞書のキャッシュをこのMacに保存します。Safari自体による通常の閲覧通信は別です。

ログイン中のユーザーのホームディレクトリから、`Library/Application Support/RTranslate/Assets/voicevox` の絶対パスを組み立て、RTranslateのモデル・辞書だけを使います。VOICEVOXのモデルやOpen JTalk基本辞書はRSpeechに同梱しません。見つからない場合は準備を案内して停止します。RTranslateの設定やファイルは変更しません。

音声を公開する場合は、[第三者ライセンス・声ごとの規約](THIRD_PARTY_NOTICES.md)とクレジット条件を確認してください。

## 開発

ビルドにはmacOSのCommand Line Toolsが必要です。音声実行環境は、ダウンロード済みRSpeechアプリから再利用できます。

```sh
python3 build.py --seed-app /Applications/RSpeech.app --output dist/RSpeech.app
```

初回の実行環境は既存RTranslateのローカル開発環境からも構成できます。ビルドはモデル等を新たにダウンロードしません。Python・モデル・ビルド成果物はGit管理から除外しています。

```sh
python3 Tests/run_reader_checks.py
npm install
npm test
dist/RSpeech.app/Contents/MacOS/RSpeech --self-test
dist/RSpeech.app/Contents/MacOS/RSpeech --audio-self-test
python3 Tests/check_common_dictionary.py --app dist/RSpeech.app
python3 Tests/check_word_scan.py --app dist/RSpeech.app
```

再生状態・URL切替・取得失敗・取得中の停止/ページ遷移、タイトル除外・段落順序、辞書の保存・編集・一括登録、再生と次文合成の重なり、声・速度・辞書の途中変更などを検証します。
Safariでの手動確認には `python3 Tests/serve_fixture.py` を起動し、表示されたURLと `/b.html` を使えます。

Mac miniで動作を確認しています。MacBook Airでの起動・速度・メモリ使用量は未検証です。
